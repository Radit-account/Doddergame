# Dodder

**Dodder** is a fast-paced browser game made with HTML5 Canvas and JavaScript. Avoid bullets and survive as long as possible!

## How to Play

1. Open `index.html` in your browser or play it on [GitHub Pages](https://radit-account.github.io/Doddergame/).  
2. Click the **START** button.  
3. Move your player using **touch** (mobile) or **mouse** (desktop).  
4. Avoid bullets coming from different directions.  
5. Your score increases as you survive longer.  
6. If you get hit, the game ends. Press **RESTART** to try again.

## Features

- Pixel-style graphics with smooth scaling.  
- Dynamic spawning bullets with increasing difficulty.  
- Touch and mouse controls supported.  
- Works directly in modern web browsers.
